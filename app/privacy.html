隐私政策

知卡（把内容变成知识卡片）· 最近更新：2026-08-26
一句话总结：我们不收集你的真实身份，不卖你的数据。你粘贴的链接、文字、截图只用于为你生成知识卡片，且由你配置的 AI 服务商处理。

1. 我们收集什么

知卡 不要求注册账号，因此默认不收集姓名、手机号、邮箱、地理位置等个人身份信息。我们仅在以下情况接触数据：

  • 你粘贴的链接 / 文本 / 截图：用于提取内容并生成知识卡片。
  • 订阅状态：由 Apple / RevenueCat 处理，用于解锁 Pro 会员功能。

2. 内容如何处理

你提供的链接、文字或图片（经设备端 OCR 转为文字后）会发送到你配置的 AI 服务商（DeepSeek / 智谱 GLM / 通义千问 / OpenAI），由其生成卡片。我们作为应用本身不中转、不留存这些请求内容。

多源摄取（文章 / 公众号 / 视频文案 / 截图识别）经由我们部署的 Cloudflare Worker 中转，仅做内容提取与转发，不存储你的原文。

3. 相机与照片权限

当你使用「截图」模式识别电子书 / 文章图片时，App 会请求相机或照片权限。图片仅在本机读取并转为文字后发送 AI 服务商，我们服务器不存储你的原图。

4. 订阅与支付

会员订阅通过 Apple App Store 内购（由 RevenueCat 协助）完成。支付由 Apple 直接处理，我们无法获取也不会存储你的信用卡号、Apple ID 密码等支付凭证。订阅记录由 Apple / RevenueCat 管理，你可随时在系统「设置 → Apple ID → 订阅」中查看或取消。

5. 数据共享与出售

我们不会向任何第三方出售你的个人信息或内容。除为完成上述生成 / 订阅所必需（即你选择的服务商与支付渠道）外，不与第三方共享。

6. 你的权利

  • 随时取消订阅（Apple 系统设置内操作）。
  • 清除本机复习数据（App 内复习区可删除）。
  • 对本政策有任何疑问，可联系我们删除相关本地数据。

7. 儿童隐私

本应用分级为 4+，不面向儿童收集信息，不含不良内容。
